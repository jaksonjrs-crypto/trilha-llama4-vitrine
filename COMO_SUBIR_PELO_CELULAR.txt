COMO SUBIR PELO APP GITHUB NO CELULAR (2 minutos):

1. Baixe o app GitHub no iPhone
2. Abra o app > + > New Repository > Nome: trilha-llama4-vitrine > Create
3. Clique em Add file > Upload files > Selecione TODOS os arquivos deste ZIP (ou só o index.html + pasta imagens se quiser simples)
4. Commit
5. Vá em Settings (no app, no navegador) > Pages > Branch: main > Save
6. Seu site vai estar em: https://seu-usuario.github.io/trilha-llama4-vitrine/

DICA: Para GitHub Pages funcionar, o arquivo principal TEM que se chamar index.html - já deixei assim!

Depois coloque o link do site no seu LinkedIn como Projeto em Destaque.
